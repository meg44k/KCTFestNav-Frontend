# 入口ページ（/main）とタイトル画面 設計

- 作成日: 2026-10-07
- 対象リポジトリ: KCTFestNav-Frontend のみ（バックエンドの変更なし）
- 期限: 高専祭（2026-10-31〜11-01）の 1 週間前、10/24 まで

## 1. 目的

今の `/main` は「マップ」のページになっているが、中身はまだ無い。上部の流れるお知らせ帯、右上のメニュー、右下の 2D/3D ボタン（押しても表示が変わるだけ）しかない。トップの `/` は「高専祭」の文字だけで、押すと `/main` に移る。

来場者が最初に開くページを、**各ページへの入口が主役で、「今」の情報を少し載せたページ**に作り替える。

成功の基準:
- QR などから開いた来場者が、タイトル画面の後、操作せずに入口ページへ着く
- 入口ページから、マップ・クラス展示・クラブバザー・ステージイベントへ 1 タップで移れる
- 演奏中のバンドがあれば、入口ページを開いただけで分かる

## 2. 決定事項（本人と合意済み 2026-10-07）

- `/main` は入口が主役（案 C）。「今」の情報（案 B）も一部入れる
- 載せる「今」の情報は、お知らせの流れる帯・演奏中のステージ・次のイベント。空いているブースは載せない
- 地図は別ページ `/map` に分ける。今回は `/map` の入れ物だけ作り、2D/3D ボタンはそこへ移し、中身は「準備中」と出す。地図そのもの（campus-3d の取り込みなど）は別に構想を練る
- `/` はタイトルを数秒見せてから自動で入口ページへ移る
- 入口は 2×2 の大きなタイル
- 右上のメニューは残す。「マップ」の行き先を `/map` に変える

## 3. 入口ページ（/main）

```
「お知らせ（流れる帯）」              [≡]
  2026 北九州高専
  高専祭
┌ 演奏中 ────────────────┐
│ Live1・第一体育館              │
│ バンドB   次: バンドC        › │
└────────────────────┘
┌──────────┐┌──────────┐
│   🗺        ││   🏪        │
│  マップ     ││ クラス展示  │
└──────────┘└──────────┘
┌──────────┐┌──────────┐
│   🍴        ││   🎤        │
│ クラブバザー││ステージイベント│
└──────────┘└──────────┘
```

上から順に:

1. **お知らせの流れる帯**: 今のもの（`BulletinBoard`）をそのまま使う
2. **タイトル**: 「2026 北九州高専」「高専祭」（今の `/` と同じ文字）
3. **ステージの帯**（§4）。出すものが無ければ帯ごと出さない
4. **入口タイル 2×2**: マップ（`/map`）、クラス展示（`/class-booth`）、クラブバザー（`/bazaar`）、ステージイベント（`/stage-event`）
   - アイコンはメニューと同じ lucide のもの（Map, Store, Utensils, MicVocal）
   - タイル全体を押せるリンクにする。高さはおよそ 7rem 以上（親指で押しやすく）
   - 並びと行き先はメニューと同じ配列 1 つから作り、ずれないようにする
5. 右上のメニュー（今の `SideMenu`）

- 60 秒ごとに自動更新（`RefreshEvery`）
- 幅 390px で、タイルとステージの帯が横にはみ出さないこと

## 4. ステージの帯

データは `GET /stage`（キャッシュしない）。表示の決まりはステージイベント画面と同じで、`src/lib/stage-schedule.ts` の関数を使い回す。

| 状態 | 出すもの |
|---|---|
| 演奏中のブロックがある（`now_playing`、どの日でも） | 1 ブロック 1 枚。「演奏中」・セクション名・場所・演奏中の出演者・次の出演者（最後なら「このブロックの最後です」） |
| 今日、時間になったのにまだ始まっていないブロックがある | 「まもなく始まります: 癒し系ミュージシャン（中庭）」 |
| 上のどちらも無く、今日これから始まるブロックがある | 「次は 14:00〜 癒し系ミュージシャン（中庭）」の 1 行 |
| どれも無い（今日の予定が終わった、当日でない） | 帯を出さない |

- 「今日」は JST の日付。今日のブロックだけを見るのは「まもなく」と「次は」だけ。演奏中は日付に関係なく出す（学生会が進めたものは必ず見えるようにする。ステージ設計書 2026-10-05-stage-schedule-design.md §3 と同じ）
- 帯は全体が `/stage-event` へのリンク（右端に ›）
- 文字の大きさはステージイベント画面より小さくする（入口が主役のため）。出演者名は太字で 1 段だけ大きく
- 取得に失敗したら帯だけ出さない（お知らせとタイルはいつもどおり出す。エラー文も出さない）

どの状態で何を出すかは純粋関数 `stageHeadline(sections, nowMs)` にまとめ、vitest で確かめる。戻り値は次のどれか:

```ts
type StageHeadline = {
  playing: NowPlaying[];                     // 日付に関係なく
  starting: { section; block }[];            // 今日の分だけ
  next?: { section; block };                 // 上の 2 つが空のときだけ。今日の分だけ
};
```

- 演奏中と「まもなく」が同時にあるときは、ステージイベント画面と同じく両方出す
- 3 つとも空なら帯を出さない

## 5. タイトル画面（/）

```
      2026 北九州高専
         高専祭
     （約 2 秒で入口へ）
```

- 今の文字の画面を残し、約 1 秒たったら `/main` へ移る。画面のどこを押してもすぐ移る
- 移るときは「2026 北九州高専 / 高専祭」がそのまま上へ動いて入口ページの見出しになり（約 1.2 秒）、お知らせ・ステージの帯・タイルは少し遅れて下から現れる（2026-10-07 本人合意）。View Transitions（`experimental.viewTransition`）を使う。対応していないブラウザではすぐ切り替わるだけ。「視差効果を減らす」の人には動かさない。他のページから入口へ戻るときは動かさない
- 移るときは履歴を置き換える（`router.replace`）。戻るボタンでタイトル画面に戻らない
- 一度見た人には出さない。見たら Cookie `kct_intro_seen=1`（30 日、path `/`）を付ける。次に `/` を開いたとき、サーバーで Cookie を見て、すぐ `/main` へ移す（画面をちらつかせない）
- JavaScript が動かなくても、押せば移れるように、画面全体は `/main` へのリンクのままにする

## 6. マップページ（/map）

- 新しく作る。タイトル「マップ」、右上のメニュー、今の 2D/3D ボタン（`MapTypeToggle` を移す）
- 中身は「マップは準備中です」の 1 行
- メニューの「マップ」の行き先を `/main` から `/map` に変える。メニューに「トップ」（`/main`）を足す

## 7. 変えるファイル

- `src/app/page.tsx` — タイトル画面（Cookie を見てすぐ移す / 2 秒で移す）
- `src/app/main/page.tsx` — 入口ページに作り替え
- `src/app/main/MapTypeToggle.tsx` → `src/app/map/MapTypeToggle.tsx` に移す
- `src/app/map/page.tsx` — 新規
- `src/components/home/` — `EntranceTiles`、`StageHeadline`（表示）、`IntroRedirect`（タイトル画面の自動移動）
- `src/lib/stage-schedule.ts` — `stageHeadline` を足す
- `src/lib/navigation.ts` — 入口とメニューで使う行き先の配列（名前・パス・アイコン）
- `src/components/layout/SideMenu.tsx/SideMenu.tsx` — 上の配列を使う。「マップ」→ `/map`、「トップ」を足す

## 8. テスト

- `stageHeadline`: 演奏中（別の日のブロックでも出る）・演奏中と「まもなく」の同時・まもなく・次は（今日のものだけ）・何も無い・演奏が終わった（current_order = 出演者数 + 1）
- 行き先の配列: 4 つの入口がメニューにも入っていること
- 実機確認: Playwright（インストール済み Chrome、390px）で `/`（初回は 1 秒後に `/main`、2 回目はすぐ `/main`）、`/main`（演奏中あり・無し・API 停止）、`/map`
